# Noto Sans Thai

These local variable WOFF2 subsets provide the `Noto Sans Thai` family for Thai, Latin Extended, and Latin glyphs. They cover font weights 100–900 and are loaded by `src/styles/foundation.css` so the app does not request a font at runtime.

Source: Google Fonts CSS API, family `Noto Sans Thai`, retrieved 2026-09-01.
License: see `OFL.txt`.

Do not replace these files with a runtime `@import` from Google Fonts. The application is designed to remain usable offline.
