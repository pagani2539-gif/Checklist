# Triage labels

| Canonical role | Label in this tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | ผู้ดูแลต้องประเมินงาน |
| `needs-info` | `needs-info` | รอข้อมูลเพิ่มเติมจากผู้แจ้ง |
| `ready-for-agent` | `ready-for-agent` | ข้อกำหนดครบ พร้อมให้ Agent ดำเนินการ |
| `ready-for-human` | `ready-for-human` | ต้องให้มนุษย์ดำเนินการหรือตัดสินใจ |
| `wontfix` | `wontfix` | จะไม่ดำเนินการ |

เมื่อ skill กล่าวถึง canonical role ให้ใช้ label ในคอลัมน์ `Label in this tracker`
