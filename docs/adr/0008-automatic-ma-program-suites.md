# ชุดตรวจโปรแกรมตามระบบที่ติดตั้งและแยกผลด้วย Snapshot

ให้รอบใหม่เปิดชุดตรวจโปรแกรมและตรวจรถอัตโนมัติตาม WIM Sorting System ที่ผูกกับ Lane ที่ใช้งานจริง โดยหนึ่งขอบเขต HS, LS หรือ IMPS มีชุดตรวจหนึ่งชุด แม้มีหลาย Lane ใช้เครื่องหมายรุ่นใน Snapshot เพื่อรักษารอบเดิมและไม่คัดลอกผลเก่าเข้าหลายระบบ ซึ่งปลอดภัยกว่าการเปลี่ยนตัวสร้างรายการย้อนหลังหรือให้ผู้ใช้ติดตั้งชุดโปรแกรมเอง

ข้อมูลรถสองงานและสองช่วงเวลา ปลายทาง หลักฐาน ความคืบหน้า และรายงานแยกเจ้าของระบบ แม้ SC HS/LS ใช้รูปแบบ API เดียวกัน ส่วน IMPS ใช้ proxy ชื่อกลุ่มแสดงผล `DATA/CONTROL CENTRAL FOR HS/LS` และรหัสแสดงผล `SC-06-HS/LS` ขยายการจัดกลุ่มเดิมโดยรักษารหัส TOR ต้นทาง 5.1/6.1 ข้อมูลทั่วไปที่ไม่มีขอบเขตยังอยู่ในกลุ่มส่วนกลางเดิม
