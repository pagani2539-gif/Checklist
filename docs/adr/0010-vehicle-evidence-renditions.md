# Vehicle API Evidence Renditions

Status: accepted

เก็บภาพที่ API ส่งมาเป็นหลักฐานต้นฉบับของรอบโดยไม่แก้ข้อมูล และเก็บ WebP ที่ย่อไม่เกิน 1,800 พิกเซลเป็นสำเนาสำหรับเปิดดูและพิมพ์ เพื่อเลื่อนงานแปลงภาพออกจากจังหวะปิดรอบและกดพิมพ์; การเตรียมภาพทำระหว่างตรวจแบบจำกัดงานพร้อมกัน และปิดรอบได้แม้เบราว์เซอร์สร้าง WebP ไม่สำเร็จ เพราะต้นฉบับยังอยู่ครบ การลบหลักฐานต้องลบไฟล์ WebP ที่ Snapshot อ้างถึงด้วย

การพิมพ์ผ่านเบราว์เซอร์ต้องทำสำเนา JPEG ชั่วคราวจาก WebP ด้วย เพราะ Chromium อาจเก็บ WebP ใน PDF เป็นภาพบีบอัดแบบไม่ลดรายละเอียดจนไฟล์ใหญ่ แม้ JPEG ชั่วคราวใหญ่กว่า WebP ก็ต้องใช้ JPEG สำหรับภาพทึบ; ภาพโปร่งใสยังใช้ PNG สำเนานี้ไม่บันทึกส่วนกลางและไม่เพิ่มไฟล์หลักฐาน คืนแหล่งภาพเดิมและยกเลิก URL ชั่วคราวเมื่อพิมพ์เสร็จหรือยกเลิก
