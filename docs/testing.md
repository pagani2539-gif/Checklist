# วิธีรันทดสอบ

ระบบค้นหาไฟล์ทดสอบจากชื่อ `tools/test_*.mjs` แต่ละไฟล์อาจมีหลายกรณีและหลายข้อยืนยัน ดังนั้นจำนวนไฟล์ไม่ใช่จำนวนกรณีทดสอบทั้งหมด การทดสอบครอบคลุมกติกาข้อมูล หน้าจอและการใช้งาน API การบันทึก PostgreSQL การเข้าสู่ระบบ ไฟล์แนบ และรายงาน

ไม่จำเป็นต้องรันทดสอบทั้งหมดหลังแก้เรื่องเล็ก ๆ ให้ใช้ชุดเร็วระหว่างทำงาน แล้วเลือกชุดที่ตรงกับส่วนที่แก้ ส่วนชุดเต็มให้ใช้ก่อนปล่อยรุ่น เพราะโค้ดส่วนกลางอาจกระทบหลายหน้า

## ชุดเร็ว

```powershell
npm.cmd run test:quick
```

ชุดนี้เลือกไฟล์เร็ว 10 ไฟล์ เพื่อตรวจ Checklist, ความคืบหน้าหน้าตรวจรถ, บริบทภาพ, การเปลี่ยนข้อมูล, การชนกันของการบันทึก, ข้อความกลาง และโครงหน้าจอ ไม่เชื่อมต่อ PostgreSQL และไม่เรียก API ภายนอก

## ชุดตามส่วนงาน

```powershell
npm.cmd run test:feature -- vehicle
npm.cmd run test:feature -- checklist
npm.cmd run test:feature -- station
npm.cmd run test:feature -- server
npm.cmd run test:feature -- reports
npm.cmd run test:feature -- ui
```

เลือกกลุ่มที่ใกล้กับสิ่งที่แก้ บางไฟล์จะอยู่มากกว่าหนึ่งกลุ่ม เพราะตรวจพฤติกรรมที่ใช้ร่วมกัน หากต้องการดูรายชื่อไฟล์ของกลุ่ม ให้ใช้ `node tools/run_all_tests.mjs --list --feature vehicle`

ถ้าไม่ได้ตั้ง `CHECKLIST_POSTGRES_TEST_DATABASE_URL` ตัวรันจะแจ้งและข้ามไฟล์ที่ต้องใช้ฐาน PostgreSQL แยก ส่วนไฟล์ที่มีทั้งการตรวจทั่วไปและการตรวจฐานข้อมูลจะยังรันการตรวจทั่วไป และแจ้งแยกเมื่อข้ามเฉพาะส่วน PostgreSQL การรันชุดย่อยโดยไม่มีฐานทดสอบจึงช่วยตรวจงานได้เร็ว แต่ยังไม่ยืนยันการบันทึกลงฐานข้อมูล

## ชุดเต็ม

```powershell
npm.cmd run test:all
```

ชุดเต็มค้นหาไฟล์ทดสอบทั้งหมดที่มีอยู่ ไม่มีการลบ test เดิมเพราะแบ่งเป็นชุดย่อย หากไม่ตั้งฐานทดสอบ ตัวรันจะแสดงจำนวนไฟล์ PostgreSQL-only ที่ข้ามไว้ ก่อนปล่อยรุ่นให้ตั้งตัวแปรไปยังฐานข้อมูลทดสอบชั่วคราวที่แยกจากข้อมูลจริง:

```powershell
$env:CHECKLIST_POSTGRES_TEST_DATABASE_URL = 'postgresql://.../checklist_test'
$env:CHECKLIST_SERVER_TEST_DATABASE_URL = 'postgresql://.../checklist_server_test'
$env:CHECKLIST_LOCAL_AUTH_TEST_DATABASE_URL = 'postgresql://.../checklist_auth_test'
npm.cmd run test:all
```

ตัวช่วยทดสอบปฏิเสธ URL ที่ชี้ไปฐานเดียวกับ `CHECKLIST_DATABASE_URL` ห้ามใช้ฐานที่มีข้อมูลปฏิบัติงานเป็นฐานทดสอบ หากผลมีรายการที่ถูกข้าม ให้รายงานว่าเป็นผลบางส่วน ไม่ใช่การยืนยัน PostgreSQL ครบชุด

ตัวรันทำงานทีละไฟล์ เพราะการทดสอบบางส่วนเปิด server ชั่วคราวหรือแก้ฐานทดสอบของตัวเอง หากต้องการดูรายชื่อทั้งหมดโดยยังไม่รัน ให้ใช้ `npm.cmd run test:all -- --list`
