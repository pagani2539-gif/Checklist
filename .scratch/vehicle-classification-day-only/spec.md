# คัดแยกประเภทรถเฉพาะกลางวัน

Status: ready-for-agent

ผู้ใช้ยืนยันให้ใช้กับรอบเก่าและรอบปัจจุบันด้วย เพราะข้อมูลยังอยู่ระหว่างทดสอบ

- คัดประเภทใช้กลางวัน 06:00–18:00 เท่านั้น ครอบคลุม HS, LS และ IMPS
- หน้าตรวจ ความคืบหน้า เงื่อนไขปิดรอบ และรายงานใช้ขอบเขตเดียวกัน
- ลิงก์คัดประเภทที่ระบุกลางคืนเปิดชุดกลางวันแทน
- ป้ายทะเบียนยังแยกกลางวันและกลางคืน
- ไม่ลบข้อมูลกลางคืนเดิม ไม่แก้ Snapshot หรือเขียนฐานข้อมูลย้อนหลัง
- ผลคัดประเภทจากข้อมูลเดิมแสดงเฉพาะกลางวันด้วย

## Validation

ทดสอบการนับผลจริง รายงาน เงื่อนไขตรวจครบ การเก็บข้อมูลเดิม และการแยกเจ้าของระบบผ่าน
ตรวจหน้าจอจากข้อมูลจำลองบน desktop/mobile รวมรายงานรอบเก่าที่ปิดแล้วผ่าน
ตรวจ /health, /ready และความตรงกันของไฟล์ที่ให้บริการบน 5220 ผ่าน
ไม่ได้บันทึกหรือเปลี่ยนผลตรวจของสถานีจริง
