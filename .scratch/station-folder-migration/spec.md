# ลดพื้นที่สำรองและตั้งชื่อโฟลเดอร์ตามด่าน

Status: ready-for-human

## เป้าหมาย

- ให้ฟอร์มสร้างสถานีเติมรหัสสถานีจากรหัสภายในไว้ก่อน และแก้เป็นรหัสทางการได้
- เก็บไฟล์ใหม่ในโฟลเดอร์ชื่อด่านที่ปลอดภัย พร้อมรหัสภายในท้ายชื่อ
- เมื่อเปลี่ยนชื่อด่าน ย้ายไฟล์พร้อมตรวจขนาดและ SHA-256 ก่อนเปลี่ยน metadata โดยคง attachment ID, Snapshot และประวัติ
- เก็บชุดสำรองใหม่ไม่เกิน 3 ชุดหลังตรวจ dump และไฟล์แนบครบ ชุดเดิมและชุดไม่สมบูรณ์คงไว้
- บันทึกแผนที่เพื่อกู้ชื่อโฟลเดอร์ให้ตรงกับ storage path ใน dump

## ข้อจำกัด

- สำรองข้อมูลปัจจุบันครบชุดก่อนย้ายไฟล์จริง และทดลองกับหนึ่งด่านก่อน
- สำรองหรือย้ายไฟล์ไม่สำเร็จต้องเก็บต้นฉบับ/ชุดก่อนหน้าไว้
- ไม่สร้างตารางสำรองอัตโนมัติ และไม่เปลี่ยน API ที่ผู้ใช้เรียก
- ชุดสำรองบนเครื่องเดียวกันยังใช้พื้นที่เดิม; การจำกัดสามชุดมีผลเฉพาะชุดใหม่ใน retention group
