# วางรูปหลักฐานจากคลิปบอร์ดในหน้า Checklist

## เป้าหมาย

ให้ผู้ตรวจคัดลอกรูป แล้วคลิกปุ่มวางรูปในช่องหลักฐานของ Checklist และกด `Ctrl+V` ได้

## ขอบเขต

- เปิดใช้เฉพาะช่องหลักฐานชนิดรูปภาพในหน้า Checklist
- รับรูปแรกจากคลิปบอร์ดครั้งละหนึ่งรูป
- ใช้การตรวจชนิดไฟล์ ขนาด 10 MB และการบันทึกหลักฐานชุดเดิม
- ไม่ดักการวางข้อความในช่องหมายเหตุ และไม่เปิดใช้กับหน้าตรวจ Vehicle API
- ช่องอ่านอย่างเดียวหรือรอบที่ปิดแล้วไม่มีปุ่มวางรูป

## เกณฑ์รับงาน

- ปุ่มวางรูปมีให้ใช้ทั้งตอนแนบรูปครั้งแรกและตอนเปลี่ยนรูป
- รูปที่วางแสดงในช่องที่เลือกและแทนรูปเดิมได้
- คลิปบอร์ดที่ไม่มีรูปแจ้งผู้ใช้ และไฟล์ที่ใหญ่เกินกำหนดถูกปฏิเสธ
- การเลือกไฟล์ ลากวาง และถ่ายรูปยังใช้ได้
- ไม่เปลี่ยนข้อมูล Snapshot หรือรูปแบบรายงาน
