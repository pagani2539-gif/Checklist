# ระบุส่วนที่ยืนยันได้จากภาพป้ายทะเบียน

Status: resolved

## พฤติกรรม

- ใต้ตรวจไม่ได้ เพิ่มปุ่มจำเป็น 3 แบบเรียงลงมา: ยืนยันได้เฉพาะเลขทะเบียน, ยืนยันได้เฉพาะจังหวัด, ยืนยันไม่ได้ทั้งคู่
- ส่วนที่ยืนยันได้ต้องกรอกค่าจากการตรวจภาพ ไม่เติมค่าจาก API ให้อัตโนมัติ
- ตัวเลือกสาเหตุเป็นปุ่ม 2 คอลัมน์ โดยคงรหัสและ 8 สาเหตุเดิมของทะเบียน ตามการเลือกครั้งล่าสุดของผู้ใช้
- บันทึก verificationScope ในรายละเอียดและประวัติ ไม่เปลี่ยนค่าต้นทางจาก API
- รายงานแสดงสาเหตุและส่วนที่ยืนยันไม่ได้ เปรียบเทียบเฉพาะส่วนที่ผู้ตรวจยืนยันได้
- ผลรวมยังเป็นตรวจไม่ได้ ไม่ให้คะแนนเหมือนถูกทั้งป้าย ข้อมูลเก่าไม่ถูกเติม scope ขึ้นเอง
- บันทึกแล้วไปคันถัดไปตามพฤติกรรมที่อนุมัติไว้
