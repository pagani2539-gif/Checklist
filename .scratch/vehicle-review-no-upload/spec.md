# เอาส่วนแนบหลักฐานเพิ่มเติมออกจากหน้าตรวจรถ

Status: resolved
Date: 2026-10-02

## Scope

หน้าตรวจป้ายทะเบียนและคัดแยกประเภทรถ ใช้ VehicleReviewDimensionActions ร่วมกัน เอาส่วนแนบ/นำไฟล์ออก ตัวเลือกไฟล์ สถานะกำลังอัปโหลด callback upload/remove และ CSS ของส่วนนี้ออก ยกเลิกเงื่อนไขต้องแนบไฟล์ก่อนบันทึกผิดหรือตรวจไม่ได้

ยังตรวจเหตุผล ส่วนที่อ่านผิด และค่าที่ผู้ตรวจยืนยันตามเดิม ไม่เพิ่มข้อบังคับเรื่องภาพให้ปุ่มถูกต้องในงานนี้

เก็บ evidenceAttachment เดิมในแบบข้อมูลและตัวแสดงรายงานเพื่ออ่านข้อมูลย้อนหลัง ไม่ลบไฟล์ในฐานข้อมูล ไม่เปลี่ยนการแนบหลักฐานของ Checklist ส่วนอื่น

## Delivery

Build สำเร็จ (คำเตือนเดิม NODE_ENV, print guard, chunk size) อัปเดต frontend localhost:5220 เก็บรุ่นเดิม release/public.before-no-review-upload-25691002-155939 ไม่ restart server /health 200

ค้นโค้ดหน้าตรวจแล้วไม่เหลือ callback upload/remove และ CSS ของส่วนแนบรายคัน เบราว์เซอร์หน้าคัดประเภทพบ input file ในแผงผลตรวจ 0 และข้อความแนบหลักฐานเพิ่มไม่มี ไม่กดบันทึกผลทดลอง
