# รับค่า API หลังเปิดรอบ
Status: ready-for-agent

เพิ่มขั้นตอนยืนยันรับค่าเชื่อมต่อจากทะเบียนสถานีในหน้าตรวจรถของรอบที่ยังเปิดอยู่ ใช้เฉพาะระบบที่มีใน Snapshot และบันทึก `vehicleConnectionUpdates` แยกจาก Snapshot พร้อมค่าเดิม ค่าใหม่ เวลา และผู้รับค่า ไม่เพิ่มระบบหรือรายการตรวจย้อนหลัง

รักษาผลตรวจและหลักฐานเดิม แยก HS/LS/IMPS และไม่เปลี่ยนรอบที่ปิดแล้ว หากระบบที่เลือกมีการดึงข้อมูลรถแล้ว (รวมผลว่าง) จะไม่เปลี่ยนปลายทาง ป้องกันความสับสนของข้อมูลและหลักฐาน Guard การบันทึกต้องตรวจสถานะรอบและชุดข้อมูลรถเพื่อป้องกันการปิดรอบหรือดึงข้อมูลพร้อมกัน

ค่าที่รับใช้ในการดึงข้อมูล การโหลดรอบซ้ำ ความพร้อมปิดรอบ และรายงาน โดยไม่รับการแก้ทะเบียนสถานีครั้งต่อไปเอง
