# ช่องเหตุผลผลตรวจถูกตัดหรือบัง

Status: resolved
Date: 2026-10-02
Order: งานถัดไปหลังปิดงานภาพหาย ตามคำขอผู้ใช้

## อาการจากภาพที่ผู้ใช้ส่ง

เมื่อเลือกอ่านไม่ถูกต้องหรือตรวจไม่ได้ ช่องเหตุผลและตัวเลือกด้านล่างแสดงไม่ครบ แถบก่อนหน้า/ถัดไปและข้อความตรวจครบทุกจุดแล้วกินพื้นที่ด้านล่าง ต้องตรวจว่าเกิดจากขนาดคงที่ การเลื่อน หรือองค์ประกอบทับกัน ยังไม่ยืนยันสาเหตุ CSS/HTML

## ขอบเขตงานถัดไป

- ตรวจแผงผลตรวจจริงทั้งอ่านถูก อ่านผิด และตรวจไม่ได้ ในหน้าจอกว้างและแคบ
- ให้ช่องรายละเอียด เหตุผล และปุ่มบันทึกเข้าถึงได้ครบ
- ตรวจข้อความตรวจครบเมื่อยังมีการแก้ที่ไม่ได้บันทึก
- รักษาผลตรวจและการบันทึกเดิม ไม่เปลี่ยนข้อมูลสถานีเพื่อทดลอง

## Answer

ยืนยันก่อนแก้บน localhost:5220: ฟอร์มจบที่ y=849 แต่แถบ navigation เริ่ม y=752 และเป็น sticky ทำให้ทับฟอร์ม ส่วน inspector ถูกกฎ overflow hidden !important จำกัดไว้

เพิ่ม ops-vehicle-focus-inspector-body ให้ฟอร์มและหลักฐานเลื่อนในพื้นที่เดียวกัน แถบ navigation อยู่ภายนอกพื้นที่เลื่อนและ position static ซ่อน completion ระหว่างเลือกสถานะใหม่ที่ยังไม่บันทึก

ตรวจด้วยเบราว์เซอร์: อ่านผิดและตรวจไม่ได้ จอปกติ จอ 1366x768 และมือถือ 430x900 มือถือไม่มีความกว้างล้น (430px) ปุ่มบันทึกอยู่ก่อน navigation ตามลำดับ ไม่กดบันทึกผลทดสอบจริง

Build สำเร็จ อัปเดต localhost:5220 แล้ว ตรวจรุ่นใช้งานจริง bodyBottom=798 footerTop=804 saveBottom=786.97 completionDisplay=none
