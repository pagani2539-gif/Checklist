# ใบงานทดสอบกับผู้ใช้

ใช้ข้อมูลจำลองในระบบทดสอบเท่านั้น ให้ผู้ทดสอบทำเองก่อน ผู้คุมจดสิ่งที่เกิดขึ้น
และให้ความช่วยเหลือเมื่อผู้ทดสอบติดขัดครบ 60 วินาที

## บทบาทและงาน

| บทบาท | งานที่ให้ทดลอง | หลักฐานที่เก็บ |
|---|---|---|
| แอดมิน | สร้างบัญชี 3 บทบาท กำหนดสถานี ระงับบัญชี และตรวจสิทธิ์ | สิทธิ์ที่ตั้งและผลที่แต่ละบัญชีมองเห็น |
| แอดมิน | สร้างสัญญา 2 ภาค เพิ่มงวด เลือกสถานี เปิดหน้าปกและรายงานงวด | รหัสสัญญา/งวด/สถานีจำลองและขั้นตอนที่ติด |
| แอดมิน | สร้างสถานี SC และ IMPS ที่มีหมวดหลักครบ เพิ่ม System, Asset และ Lane | ชื่อ/รหัสกลุ่ม จำนวนอุปกรณ์ Scope และความสัมพันธ์แม่/ลูก |
| หน้างาน | เปิดรอบแบบผูกสัญญาและแบบด่วน แล้วหาหมวด `1.1`, `.01` และ `.02` | เวลาทำงาน จุดที่ต้องถาม และรายการที่เลือก |
| หน้างาน | กรอกผลตรวจ หมายเหตุ และรูปหลักฐาน จากนั้นโหลดใหม่และตัดเน็ตชั่วคราว | ค่าก่อน/หลังโหลด ข้อความบันทึก และหลักฐาน |
| หัวหน้า | ตรวจความพร้อม ปิดรอบ เปิดประวัติ พิมพ์/ส่งออกรายงาน | ผลปิดรอบและความตรงกับข้อมูล Snapshot |
| หัวหน้า | สร้างฉบับแก้ไขจากรอบเก่าและกลับไปตรวจรอบต้นฉบับ | รหัสรอบเดิม/ใหม่และค่าที่ต้องไม่เปลี่ยน |
| ทุกบทบาท | ค้นหา กรอง ย้อนกลับ เปิดหน้าว่าง/ผิดพลาด และลองเข้าข้ามสถานี | ผลการค้นหา สิทธิ์ ข้อความผิดพลาด และเวลาที่ใช้ |

## ตรวจหมวด SC/IMPS

ทำซ้ำทั้ง SC และ IMPS ตรวจว่ามีเฉพาะกลุ่มของรูปแบบนั้นและรหัส `.01`/`.02`
ตรงกันในหน้าสร้างสถานี ทะเบียน Checklist และรายงาน ประเภท WIM/LPR/CCTV/VMS
ต้องเป็นป้ายชื่อประกอบ กลุ่มหลักยังเป็นรหัสสถานี กดรายการแล้วต้องเปิด System/Asset
ที่ถูกต้อง รายการประวัติให้ยึด Snapshot เดิม

## หน้าจอ

ทุกหน้าจอให้บันทึกภาพที่ความกว้าง CSS จริง 390, 768, 1440; หน้าหลัก 7 ประเภท
เพิ่ม 320, 375, 1024 ตรวจแนวตั้ง/แนวนอนบน Android และ iPhone จริงด้วย

## บันทึกปัญหา

ใช้ช่อง: บทบาท, เส้นทาง, อุปกรณ์/ความกว้าง, ขั้นตอนทำซ้ำ, ผลที่ควรได้,
ผลที่พบ, ความรุนแรง, ภาพ, และสถานะ `needs-triage`/`needs-info`/
`ready-for-agent`/`ready-for-human`/`wontfix`.
