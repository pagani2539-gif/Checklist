# ข้อความยืนยันตัวตนบนหน้าบัญชีผู้ใช้ไม่มีคำแนะนำถัดไป

Type: ux
Status: needs-triage
Priority: low
Severity: minor
Blocked by: test authentication session

## เส้นทางและอุปกรณ์

- บทบาท: แอดมินที่ยังไม่มี session หรือสิทธิ์
- เส้นทาง: `#/admin/users`
- อุปกรณ์: Browser viewport 390 CSS px
- ภาพ: `../screenshots/admin-users-390.png`

## ทำซ้ำ

1. เปิดหน้าจัดการบัญชีในระบบ Local ที่ไม่มีบัญชีทดสอบ
2. ดูข้อความผิดพลาดและช่องกรอกบัญชีที่แสดงอยู่ด้านล่าง

## ผลที่ควรได้

ผู้ใช้ควรเห็นคำอธิบายภาษาไทยและวิธีดำเนินการ เช่น เข้าสู่ระบบหรือขอสิทธิ์ก่อนจัดการบัญชี หรือฟอร์มควรถูกซ่อน/ปิดจนกว่าจะยืนยันตัวตน

## ผลที่พบ

แสดงข้อความภาษาอังกฤษ `Authentication required` โดยไม่มีปุ่มหรือคำแนะนำการแก้ไข และยังแสดงช่องสร้างบัญชี ผู้ใช้ไม่ทราบว่าควรทำอย่างไรต่อ

## ความรุนแรงและข้อจำกัด

เล็กน้อยในรอบนี้ เพราะไม่มีบัญชีทดสอบให้ตรวจเส้นทางที่ได้รับอนุญาต ต้องให้เจ้าของระบบยืนยันว่าการยืนยันตัวตนทำผ่านระบบภายนอกหรือมีหน้าล็อกอินอื่น ก่อนจัดเป็นข้อบกพร่องที่ต้องแก้
