# มือถือต้องเลื่อนยาวเพื่อดู Work Spec ของหมวดที่เลือก

Type: ux
Status: ready-for-agent
Priority: medium
Severity: moderate
Blocked by: none

## เส้นทางและอุปกรณ์

- บทบาท: ผู้สร้าง/แก้ข้อมูลสถานี
- เส้นทาง: `#/stations/new` ขั้น 2 ระบบและอุปกรณ์
- อุปกรณ์: Browser viewport 320 และ 390 CSS px
- ภาพ: `../screenshots/station-new-step2-imps-selected-390.png`, `../screenshots/station-new-step2-imps-detail-390.png`

## ทำซ้ำ

1. เปิด Wizard สร้างสถานี เลือกรูปแบบ IMPS และกรอกข้อมูลจำลองในขั้นแรก
2. ไปขั้น 2 แล้วเลือก IMPS-01 ที่อยู่บนหน้าจอ
3. สังเกตว่าหน้าไม่เลื่อนไปยัง Work Spec ของ IMPS-01
4. เลื่อนหน้าลงผ่านรายการหมวดทั้ง 6 รายการเพื่อดู Work Spec

## ผลที่ควรได้

ผู้ใช้ควรรู้ว่ารายละเอียดของหมวดอยู่ตรงไหน และเข้าถึงรายการระบบ/อุปกรณ์ของหมวดที่เลือกได้สะดวกบนมือถือ

## ผลที่พบ

บนมือถือหมวดทั้ง 6 เรียงแนวตั้งและอยู่ก่อน Work Spec; จุดเริ่ม Work Spec อยู่ต่ำจากบนหน้าประมาณ 1,081 px ที่ความกว้าง 390 และ 1,179 px ที่ความกว้าง 320 การแตะ IMPS-01 ที่มองเห็นได้ทำให้หมวดถูกเลือก แต่ `scrollY` ยังเป็น 0 ข้อความแนะนำบนหน้าระบุให้เลือกหมวด “ทางซ้าย” และดู Work Spec “ตรงกลาง” ซึ่งไม่ตรงกับหน้าจอมือถือ

ไม่มีการล้นแนวนอนระดับทั้งหน้า ปัญหานี้เป็นเรื่องระยะทางและคำแนะนำการใช้งาน

## ผลกระทบและแนวทาง

ผู้ใช้ต้องค้นหารายละเอียดเองหลังเลือกหมวด และอาจไม่รู้ว่าการแตะทำให้เกิดผลตรงส่วนใด ควรใช้คำแนะนำที่ไม่ผูกกับตำแหน่งจอ และพิจารณาพาไปยังรายละเอียดของหมวดที่เลือกหรือแสดงรายละเอียดติดกับตัวเลือกบนมือถือ

## ความรุนแรง

ปานกลาง: กระทบเส้นทางตั้งค่าหมวดหลักบนมือถือ แต่ยังทำต่อได้ด้วยการเลื่อนหน้า
