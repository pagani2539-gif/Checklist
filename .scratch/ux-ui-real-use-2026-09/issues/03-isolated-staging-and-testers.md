# 03: เตรียมระบบแยกและผู้ทดสอบก่อน UAT

Type: test-readiness
Status: ready-for-human
Priority: blocking
Blocked by: none

## สิ่งที่ต้องเตรียม

- URL ระบบทดสอบที่ยืนยันฐานข้อมูลและพื้นที่ไฟล์แนบแยกจากระบบจริง
- บัญชีจำลองแยก Field, Admin และ Supervisor พร้อมขอบเขตสถานี
- ข้อมูล SC/IMPS, สัญญา, งวด, หลักฐาน และปลายทาง Vehicle API สำหรับทดสอบ
- ผู้ทดสอบอย่างน้อย 2 คนต่อบทบาท และอุปกรณ์ Android/iPhone จริง

## เหตุผล

ไม่มี `CHECKLIST_POSTGRES_TEST_DATABASE_URL` หรือชุดบัญชีทดสอบในสภาพแวดล้อมนี้
ค่าโครงการเลือก Server/PostgreSQL อยู่ จึงไม่เริ่ม flow ที่อาจเขียนข้อมูลส่วนกลาง
ไม่มีผู้ทดสอบจริงให้เก็บคะแนนการทำงานเองตามเกณฑ์ 80%

## เกณฑ์พร้อมเริ่ม

ผู้ดูแลยืนยันระบบ/ฐานข้อมูล/พื้นที่ไฟล์แนบว่าเป็น Test แยก พร้อมบัญชีทดสอบ
และผู้ทดสอบครบ 6 คน ก่อนเริ่ม `test-cases.md`
