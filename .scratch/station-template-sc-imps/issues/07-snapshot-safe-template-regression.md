# 07: ยืนยันความปลอดภัยของ Snapshot และทดสอบการทำงานร่วมทั้งระบบ

**What to build:** การใช้แม่แบบ SC/IMPS ใหม่และการปรับ Station Profile ต้องมีผลเฉพาะสถานีปัจจุบันและ Inspection Snapshot ที่สร้างหลังการแก้ไข ประวัติ ผลตรวจ สถานะ และไฟล์หลักฐานของรอบเดิมต้องคงเดิม
