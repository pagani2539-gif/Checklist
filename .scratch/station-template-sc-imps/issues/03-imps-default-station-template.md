# 03: สร้างรายการตั้งต้นสำหรับรูปแบบสถานี IMPS

**What to build:** เมื่อผู้ใช้เลือก IMPS ระบบต้องสร้างรายการระบบและอุปกรณ์ตั้งต้นที่เป็นฐานร่วมของ Image Processing System โดยไม่แยกแม่แบบขาเข้ากับขาออก และเปิดให้ปรับ Station Profile ตามอุปกรณ์จริง

**Blocked by:** 01: กำหนดค่าเริ่มต้นสองเลนสำหรับรูปแบบสถานี SC และ IMPS.

**Status:** resolved

- [x] ตัวเลือกแม่แบบที่ผู้ใช้เห็นยังมีชื่อหลักว่า IMPS เพียงรายการเดียว
- [x] IMPS สร้างรายการตั้งต้นสำหรับ Image Processing, WIM, LPR, CCTV และระบบส่วนควบ
- [x] IMPS ไม่สร้าง VMS โดยอัตโนมัติ แต่ผู้ใช้เพิ่ม VMS ภายหลังได้
- [x] ขาเข้าและขาออกเป็นข้อมูลชื่อหรือตำแหน่งของ Station Profile ไม่ใช่ชนิดแม่แบบ
- [x] รายการระบบซอฟต์แวร์แยกยอดจากอุปกรณ์จริง
- [x] การทดสอบยืนยันรายการตั้งต้น จำนวนเริ่มต้น และการสร้างรอบใหม่จาก IMPS
