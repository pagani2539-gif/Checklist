# 04: รองรับชื่อ TOR และการจับคู่ประเภทอุปกรณ์กลาง

**What to build:** ผู้ใช้ต้องเห็นชื่อรายการตาม TOR เป็นชื่อหลักของสถานีแต่ละแห่ง ขณะที่ระบบยังใช้รหัสประเภทกลางที่คงที่เพื่อจัดกลุ่มรายการตรวจ ค้นหา และป้องกันการสร้างอุปกรณ์ซ้ำจากชื่อที่เขียนต่างกัน

**Blocked by:** 02: สร้างรายการตั้งต้นสำหรับรูปแบบสถานี SC; 03: สร้างรายการตั้งต้นสำหรับรูปแบบสถานี IMPS.

**Status:** resolved

- [x] อุปกรณ์จริงเก็บทั้ง sourceLabel จาก TOR และรหัสประเภทกลาง
- [x] หน้าทะเบียนแสดงชื่อ TOR เป็นชื่อหลักโดยยังแสดงหมวดหรือประเภทกลางได้
- [x] ชื่อ LPR CAMERA, กล้อง Fixed, กล้องปรับมุม, NVR และ Cabinet ที่เขียนต่างกันยังจับคู่ประเภทกลางเดียวกันเมื่อเป็นอุปกรณ์ชนิดเดียวกัน
- [x] กล้องชื่อเหมือนกันแต่ทำหน้าที่ต่างบริบทสามารถใช้ sourceLabel แยกบริบทโดยไม่เปลี่ยน identity
