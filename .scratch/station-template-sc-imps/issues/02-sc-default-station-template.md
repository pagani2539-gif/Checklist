# 02: สร้างรายการตั้งต้นสำหรับรูปแบบสถานี SC

**What to build:** เมื่อผู้ใช้เลือก SC ระบบต้องสร้างรายการระบบและอุปกรณ์ตั้งต้นที่เป็นฐานร่วมของสถานี Spot Check โดยไม่ผูกแม่แบบกับชื่อระนองหรือราชบุรี และเปิดให้ปรับรายการตามอุปกรณ์จริงของแต่ละ Station Profile

**Blocked by:** 01: กำหนดค่าเริ่มต้นสองเลนสำหรับรูปแบบสถานี SC และ IMPS.

**Status:** resolved

- [x] ตัวเลือกแม่แบบที่ผู้ใช้เห็นยังมีชื่อหลักว่า SC เพียงรายการเดียว
- [x] SC สร้างรายการตั้งต้นที่จัดกลุ่ม WIM, LPR, CCTV, ระบบส่วนควบ และ VMS อย่างชัดเจน
- [x] รายการ TOR ที่เป็นระบบหรือซอฟต์แวร์แยกบทบาทจากอุปกรณ์จริงด้วย Mapping 3 ชั้น
- [x] ผู้ใช้เพิ่ม ลด หรือปิดใช้งานอุปกรณ์ให้ตรงกับสถานีจริงก่อนบันทึกได้
- [x] ไม่มีชื่อระนองหรือราชบุรีฝังเป็นชนิดแม่แบบ
- [x] การทดสอบยืนยันรายการตั้งต้น จำนวนเริ่มต้น และการสร้างรอบใหม่จาก SC
