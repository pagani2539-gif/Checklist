# 05: รองรับจำนวนอุปกรณ์จริงที่ต่างกันในแต่ละ Station Profile

**What to build:** หลังเลือก SC หรือ IMPS ผู้ใช้ต้องปรับจำนวนอุปกรณ์จริงของสถานีได้โดยไม่เปลี่ยนแม่แบบกลาง จำนวนดังกล่าวเป็นข้อมูลหลักสำหรับสร้างรายการตรวจและช่องหลักฐานของรอบใหม่

**Blocked by:** 02: สร้างรายการตั้งต้นสำหรับรูปแบบสถานี SC; 03: สร้างรายการตั้งต้นสำหรับรูปแบบสถานี IMPS; 04: รองรับชื่อ TOR และการจับคู่ประเภทอุปกรณ์กลาง.

**Status:** resolved

- [x] ผู้ใช้เพิ่ม ลด และปิดใช้งานอุปกรณ์เป็นรายประเภทได้
- [x] Station Profile ของสถานีรูปแบบเดียวกันเก็บจำนวนอุปกรณ์ต่างกันได้
