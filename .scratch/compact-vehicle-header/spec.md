# ปรับหัวหน้าตรวจรถให้กระชับ

Status: ready-for-agent

## ขอบเขตที่ผู้ใช้อนุมัติ
หน้าตรวจรถ API ป้ายทะเบียนและคัดแยกประเภทรถ HS, LS, IMPS กลางวัน กลางคืน และประวัติ ไม่รวม Checklist อุปกรณ์

## ผลที่ต้องได้
- ย้าย URL ถาวรไปหน้าต่าง การเชื่อมต่อ API แสดงค่ารอบ/ทะเบียนสถานีและรับค่าใหม่ด้วยเงื่อนไขเดิม
- รวมระบบ งานตรวจ รายละเอียดชุดทดสอบ API รายงาน และกลับรายการในแถบเดียวที่แบ่งแถวได้
- ช่วงเวลายังเลือกได้เมื่อพับรายละเอียด คัดแยกมีเฉพาะกลางวัน
- สรุปผลกระชับ ย้ายไปคันค้างไว้หัวคิว ก่อนดึงแสดงเวลา/จำนวนรถ หลังดึงพับรายละเอียด
- คิวและรายละเอียดเลื่อนภายในบนคอมพิวเตอร์ ปุ่มก่อนหน้า/ถัดไปยังเห็น มือถือคงรูปแบบเลื่อนเดิม
- หน้าต่างรองรับ Tab, Shift+Tab, Escape, คืนโฟกัส และ URL ยาวตัดบรรทัด
- ไม่แก้คะแนน ผลตรวจ หลักฐาน หรือ Snapshot ประวัติอ่านอย่างเดียว

## เกณฑ์ตรวจรับ
ภาพก่อน/หลัง 1920x1080, 1280x720, 768x1024, 390x844 โหมดสว่าง/มืด พื้นที่เพิ่ม >=120px ที่ 1920x1080 หลังดึงและพับรายละเอียด ตรวจผลว่าง เตรียมภาพ บันทึกล้มเหลว รอบปิด สลับบริบท รายงาน และรับค่า API ยืนยัน/ยกเลิก จากนั้นสร้างเว็บและตรวจไฟล์ที่บริการ 5220 ส่ง
